# MathQuest — Trigonometric Calculus and Direction-Triangle Update

MathQuest provides randomised foundation-mathematics practice for EG1011.

## Topics

- Linear equations
- Trigonometry
- Vector components
- Differentiation
- Integration

## New in this version

- trigonometric differentiation:
  - sine
  - cosine
  - tangent
  - chain rule
- sinusoidal position, velocity and acceleration
- trigonometric integration:
  - sine
  - cosine
  - tangent
- sinusoidal acceleration integrated using an initial velocity
- revised small direction-triangle vector diagram showing:
  - force vector
  - x- and y-component construction
  - rise/run triangle on the vector
  - unit-direction calculation

## Run on Windows

Double-click `START_MATHQUEST.bat`.

Use `REPAIR_AND_START.bat` if the local environment needs rebuilding.
